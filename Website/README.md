# Hotel Management System - Public Pages

A modern, responsive hotel website featuring a beautiful home page and comprehensive room booking system.

## 🌟 Features

### 🏠 Home Page
- **Hotel Introduction**: Elegant presentation with hero section and hotel information
- **Attractive Images**: High-quality hotel imagery showcasing luxury and comfort
- **Quick Links**: Easy access to key hotel services and information
- **"Book Now" Button**: Direct navigation to the booking page
- **Navigation Bar**: Clean navigation with Home, Rooms, and Contact links

### 🛏️ Room Search & Booking Page
- **Advanced Search Filters**:
  - Check-in/Check-out dates
  - Room type selection
  - Price range filtering
  - Number of guests
  - Amenities preferences
- **Room Listing Cards**: Beautiful cards displaying:
  - Room images
  - Detailed amenities
  - Pricing information
  - "Book Now" options
- **Booking Form**: Complete booking system with:
  - Customer name and contact details
  - ID proof upload functionality
  - Payment method selection
  - Booking confirmation

## 🎨 Design Features

- **Modern UI/UX**: Clean, professional design with glass morphism effects
- **Responsive Design**: Fully responsive across all devices
- **Smooth Animations**: Engaging hover effects and transitions
- **Professional Typography**: Poppins font family for excellent readability
- **Color Scheme**: Elegant gradients and modern color palette

## 🚀 Getting Started

1. **Download the files** to your local machine
2. **Open `home.html`** in your web browser to view the home page
3. **Click "Book Now"** or navigate to "Rooms" to access the booking page
4. **Explore the features** and test the booking functionality
